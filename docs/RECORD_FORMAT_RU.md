# Heap Record Format (экспериментальный)

Формат предназначен для раннего Record Manager поверх `.zdb`. Значения одной записи пока помещаются в одну страницу. До добавления continuation/overflow для больших значений формат нельзя считать v1.0-stable.

## Table root page

Страница таблицы (`PageType::Table`) хранит:

| Смещение в payload | Тип | Значение |
|---:|---|---|
| 0 | uint32 LE | magic `RBT1` (`0x31544252`) |
| 4 | PageId LE | head страницы записи; 0 означает пустую таблицу |

`usedBytes=0` трактуется как новая пустая таблица для совместимости с созданными ранее корневыми страницами. Иначе `usedBytes` должен быть не меньше 8.

## Record page

Каждая запись занимает отдельную `PageType::Overflow`:

| Смещение | Тип | Значение |
|---:|---|---|
| 0 | uint32 LE | magic `REC1` (`0x31434552`) |
| 4 | PageId LE | следующая запись в цепочке; 0 — конец |
| 8 | uint32 LE | версия записи, сейчас 1 |
| 12 | uint32 LE | длина бинарного ключа |
| 16 | uint32 LE | длина бинарного значения |
| 20 | uint32 LE | flags: 0 live, 1 tombstone |
| 24 | bytes | ключ, затем значение |

Поле `PageHeader.usedBytes` обязано быть равно `24 + key length + value length`. Пустые ключи запрещены. Флаг 1 зарезервирован под tombstone; текущий erase атомарно отвязывает страницу и освобождает её. Ключ должен быть уникальным среди live записей.

## Запись и восстановление

Вставка записывает новую страницу и ссылку в корне одной WAL-транзакцией вместе с изменениями каталога страниц, free-list и, при росте файла, заголовка базы. Обновление записи журналирует её страницу. Удаление одной записи освобождает страницу в той же транзакции, которая обновляет ссылку в цепочке. Удаление таблицы освобождает корень и принадлежащие ей страницы записей.

Базы из ранней экспериментальной версии открываются с прежним форматом записей. Если та версия оставила страницу после прерванной вставки, проверка при открытии сохраняет непривязанную страницу. Новая вставка устраняет причину появления таких страниц.

CRC страницы проверяется FileManager, а runtime при открытии проверяет формат и всю цепочку на циклы, неверные длины, владельца, page type и повторяющиеся live keys. Длина `key + value + 24` ограничена payload одной страницы (`Page::kV2PayloadSize`); большие значения отклоняются до записи.

Этот формат пока не гарантирует batch-транзакции нескольких ключей, B+Tree индексацию, MVCC или транзакционную изоляцию. До стабилизации формата будущие несовместимые изменения требуют версии формата и миграционного описания.
